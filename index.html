Projects

2 DOF Robotic Arm for Alphabet and Number Tracing

Developed and simulated a 2-DOF robotic arm in MATLAB/Simulink for tracing alphabets and numbers from input images. The system performs image preprocessing and converts input characters into XY coordinate paths using a MATLAB-based UI, where users can select a letter or number to be traced. These coordinates are fed into a Simulink model that implements inverse kinematics, forward kinematics, and PID control to accurately track the desired trajectory. The associated research paper was accepted and presented at the IEEE CCGE Conference (May 7–8, 2026).

Embedded Edge AI for Sleep Apnea and Snoring Detection using STM32 and NanoEdge AI

Developed a real-time embedded snoring detection system using an STM32 microcontroller and NanoEdge AI Studio. The system classifies normal snoring, apnea-related patterns, and background noise entirely on-device without pre-collected datasets. Using a MAX4466 microphone and TinyML-based model generation, the solution enables lightweight edge inference with high efficiency. The system achieved 93.93% accuracy while using only 2.5 KB RAM and 4 KB Flash.
